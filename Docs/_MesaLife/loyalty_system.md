# Система лояльности (Civic Status) — MesaLife

Дизайн-документ. Согласовано 12.11.2026. Референс: Project Synapse
(Garry's Mod HL2RP, project-synapse.fandom.com/wiki/Civil_Status).

> **Статус реализации (12.11.2026):** MVP реализован — `LoyaltySystem`
> (персистентность через playtime-трекер `MLLoyalty`, старт 50, таяние −5/раунд,
> API `AddPoints`, экзамин ступени), админ-команды `addloyal`/`getloyal`,

> пороги должностей.

## Идея

Лоялист — не роль и не перка, а **персистентные очки лояльности**, привязанные
к **аккаунту** (одна репутация на всех персонажей игрока — закрыт абуз со
сбросом минуса созданием нового персонажа). В списке ролей остаётся только
«Гражданин»; должности открываются порогом очков, вступление — в раунде.

## Носитель и хранение

- `LoyaltyPoints` (int, может быть < 0), привязан к аккаунту
- Персистентно между раундами; смерть персонажа не сбрасывает
- Стартовое значение: **50** (новичок = Гражданин)
- Кап: **1000**
- Хранение: механизм персистентных данных аккаунта (user DB / трекеры —
  уточнить при реализации)

## Ступени статуса (шкала Synapse)

| Статус | Очки | Бонусы |
|---|---|---|
| Non-Citizen | 0–49 | без рационов, без жилья, CP наказывает за мелочи; реабилитация через работу |
| Гражданин | 50–249 | стандартный паёк |
| Priority-3 | 250–499 | улучшенный паёк |
| Priority-2 | 500–749 | приоритетный паёк + доступы к лоялист-зонам, доверие CP |
| Priority-1 | 750–1000 | максимум пайка, полное доверие CP (не иммунитет к Civil Code) |

Ступени и бонусы — data-driven прототипы (пороги/паёк/доступы/локаль),
крутить без перекодирования.

## Пороги должностей

Вступление **в раунде** через диспетчера (NPC-консоль, позже игрок-чиновник).
Очки при вступлении НЕ списываются (это доступ, не покупка). Изгнание снимает
должность; повторное вступление — снова через порог.

| Должность | Порог очков |
|---|---|
| Полноценный рабочий / врач | 100 |
| Рабочий химзащиты (Infestation Control) | 250 |
| Бригадир / учёный | 400 |
| Гражданская оборона (Civil Defense) | 600 |

## Динамика очков

- **Таяние: −5 за раунд** («проживание» — город всё съедает). Лояльность —
  поддерживаемая величина, не накопленный капитал.
- **Заводы:** +1…2 за сданное изделие, **лимит начислений в час** на игрока
  (анти-афк-гринд). У игроков в минусе — **×2** (догоняющая трудовая
  повинность, не пожизненное клеймо).
- **Смены диспетчера:** отметился на смену → в конце смены +N за присутствие
  (множитель от статуса — рассмотреть). Основной RP-источник дохода.
- **CP-вердикты** (команды с записью в админ-лог; пока CP-игроков нет —
  админ/NPC): донос +15, содействие обыску +5, нарушение −20, стычка с
  CP −50.

## Минус (штрафной режим)

При очках < 0: вендор рационов отказывает, двери жилья не пускают, CP вправе
наказывать. Механика догоняющая: отработал на заводах (×2) — вернулся в ноль.

## Отображение

- Экзамин ID-карты: ступень («Priority-2 гражданин»)
- CP: точное число (экзамин/команда)
- Повстанцы: видят ступень → «коллаборационист = цель»

## Выводы из референса Synapse

- Их Tasks-система начисления очков «barely used ingame» — гринд-фабрик в
  одиночку не тянет: поэтому у нас два источника (заводы + смены) и лимит в час.
- Персистентность даёт ветеранский разрыв — таяние −5/раунд держит всех на
  беговой дорожке.
- Очки = доступ к должностям и качество жизни (паёк), а не боевая сила.
